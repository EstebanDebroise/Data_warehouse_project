Project documentation contains 2 parts: the first one deals with building a data warehouse, and the second part deals with BI/creating reports.

The documentation should include at least the following elements:

- description of the domain/process covered with the data warehouse (motivation for buildign the DW) + description of used technologies

- description of the dataset (data source, data structure...)

- description of the DW star schema model

- description of the ETL process

- at least 3 reports built in selected BI tool

In your project, it is advisable that you apply as many concepts covered during lab exercises as possible (especially in the BI part).
